功能

围绕 SSH 会话与文件传输展开,不夹带多余的东西。

三种认证方式

密码、OpenSSH 私钥与 SSH Agent。密码与私钥口令只在当前连接中使用,不持久化。

交互式终端

真实 PTY,多标签切换,自动适配窗口尺寸,兼容 vim、tmux 等全屏程序。

独立 SFTP 面板

悬浮文件面板使用独立连接,传输文件时终端输入输出不受影响。

主机指纹校验

首次连接确认并本地保存主机指纹,指纹发生变化时阻止连接并告警。

传输进度与原子替换

实时进度与速度显示,可随时取消。临时文件完成后原子替换,失败或取消不污染目标文件。

离线命令手册

内置常用 Linux 命令与参数说明,无需联网即可查阅。

终端

后台非阻塞读写,保持击键即时响应,断线状态可识别。

  • 多终端标签、自适应尺寸,断线与退出码识别
  • SSH keepalive 与后台非阻塞 I/O
  • 兼容 vim 的 bracketed paste,多行粘贴安全确认
  • 终端内容查找、浅色 / 深色主题、字体大小设置
  • 复制、粘贴、清屏、重连与常用快捷键
  • 可选会话日志记录,支持本地 PowerShell

安全

凭据不落盘,操作显式触发。

01

主机指纹校验

首次连接确认服务器主机指纹并本地保存;后续指纹发生变化时阻止连接并告警。

02

凭据不持久化

密码与私钥口令只在本次连接中传给 Rust 后端,不写入磁盘;会话参数仅保存在本地 WebView 存储。

03

原子替换

上传、下载与删除均由用户显式触发;传输失败或取消通过临时文件与原子替换,保证目标文件不被污染。
